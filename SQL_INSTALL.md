# SQL запити для реєстрації шаблону TechnoDron в ocStore 2.3.0.2.4

## Варіант 1: З префіксом oc_ (стандартний)

```sql
INSERT INTO `oc_extension` (`extension_id`, `type`, `code`)
VALUES (NULL, 'theme', 'tehnodron');
```

## Варіант 2: Якщо префікс інший

Спочатку знайдіть ваш префікс - подивіться які таблиці є в базі даних.
Якщо бачите таблиці типу `shop_user`, `shop_product` - значить префікс `shop_`

Замініть `oc_` на ваш префікс:

```sql
INSERT INTO `ВАШ_ПРЕФІКС_extension` (`extension_id`, `type`, `code`)
VALUES (NULL, 'theme', 'tehnodron');
```

## Варіант 3: Перевірити існуючі шаблони

Подивіться які шаблони вже зареєстровані:

```sql
SELECT * FROM `oc_extension` WHERE `type` = 'theme';
```

Ви маєте побачити записи для `default` та `newstore`.

## Варіант 4: Якщо таблиця extension не існує

Можливо в вашій версії структура інша. Спробуйте знайти таблицю:

```sql
SHOW TABLES LIKE '%extension%';
```

або

```sql
SHOW TABLES LIKE '%theme%';
```

## Після додавання запису:

1. Очистіть кеш в адмін-панелі: Система → Обслуговування → Очистити
2. Оновіть сторінку налаштувань
3. Шаблон `tehnodron` має з'явитися в списку
