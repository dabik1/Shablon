# Інструкція з встановлення шаблону TechnoDron

## Передумови

Перед встановленням переконайтеся, що у вас:
- Встановлена ocStore версії 2.3.0.2.4
- Доступ до FTP або файлового менеджера хостингу
- Доступ до адмін-панелі ocStore

## Швидке встановлення

### 1. Завантаження файлів

**Через FTP:**
```
1. Підключіться до вашого сервера через FTP
2. Завантажте папку catalog/ в корінь вашої установки ocStore
3. Файли мають злитися з існуючими папками
```

**Через cPanel File Manager:**
```
1. Увійдіть в cPanel
2. Відкрийте File Manager
3. Перейдіть до кореневої папки ocStore
4. Завантажте архів з шаблоном
5. Розпакуйте архів
```

### 2. Встановлення прав доступу

Встановіть права доступу (CHMOD) для папок:
```
catalog/view/theme/tehnodron/ - 755
catalog/view/theme/tehnodron/template/ - 755
catalog/view/theme/tehnodron/stylesheet/ - 755
```

### 3. Активація шаблону

1. Увійдіть в адмін-панель ocStore
2. Перейдіть: **Система** → **Налаштування**
3. Натисніть **Редагувати** навпроти вашого магазину
4. Перейдіть на вкладку **Магазин**
5. У випадаючому списку **Шаблон** оберіть `tehnodron`
6. Натисніть **Зберегти**

### 4. Очищення кешу

Після активації шаблону:
1. Перейдіть: **Система** → **Обслуговування**
2. Натисніть **Очистити** біля всіх пунктів
3. Оновіть головну сторінку магазину (Ctrl+F5)

## Детальне налаштування

### Налаштування логотипу

1. Підготуйте логотип:
   - Формат: PNG з прозорим фоном
   - Рекомендований розмір: 200x60 пікселів
   - Максимальний розмір файлу: 2 МБ

2. Завантаження:
   - **Система** → **Налаштування** → **Редагувати**
   - Вкладка **Магазин**
   - Поле **Логотип** → натисніть на зображення
   - Завантажте ваш логотип
   - Збережіть зміни

### Налаштування кольорів

Для зміни кольорової схеми відредагуйте файл:
`catalog/view/theme/tehnodron/stylesheet/stylesheet.css`

**Основні кольори:**
```css
/* Червоний акцент (кнопки, лінки) */
#e74c3c → замініть на ваш колір

/* Темний фон (шапка, футер) */
#2c3e50 → замініть на ваш колір

/* Зелений (кнопка "В кошик") */
#27ae60 → замініть на ваш колір
```

### Налаштування головної сторінки

#### Зміна слайдера:

1. **Система** → **Дизайн** → **Банери**
2. Створіть новий банер або відредагуйте існуючий
3. Завантажте зображення (рекомендований розмір: 1920x600px)
4. **Система** → **Дизайн** → **Макети**
5. Додайте модуль "Слайдшоу" на головну сторінку

#### Додавання рекомендованих товарів:

1. **Система** → **Дизайн** → **Макети**
2. Оберіть маршрут `common/home`
3. Додайте модуль **Рекомендовані**
4. Виберіть товари для відображення
5. Збережіть

### Налаштування контактів

Відредагуйте файл: `catalog/view/theme/tehnodron/template/common/footer.tpl`

Знайдіть розділ:
```php
<li><i class="fa fa-map-marker"></i> Адреса магазину</li>
<li><i class="fa fa-phone"></i> Телефон: +380</li>
<li><i class="fa fa-envelope"></i> Email: info@tehnodron.in.ua</li>
```

Замініть на ваші контакти.

### Налаштування категорій на головній

Відредагуйте: `catalog/view/theme/tehnodron/template/common/home.tpl`

Знайдіть блоки:
```html
<div class="category-box">
  <div class="category-icon">
    <i class="fa fa-video-camera"></i>
  </div>
  <h3>Камери відеоспостереження</h3>
  <p>IP, AHD, аналогові камери</p>
  <a href="#" class="btn btn-default">Переглянути</a>
</div>
```

Змініть іконки, назви та посилання під ваші категорії.

**Іконки Font Awesome:**
- Камери: `fa-video-camera`
- Реєстратори: `fa-hdd-o`
- Сигналізація: `fa-bell`
- Контроль доступу: `fa-key`
- [Більше іконок](https://fontawesome.com/v4/icons/)

### Налаштування SEO

1. **Система** → **Налаштування** → **Магазин**
2. Заповніть:
   - **Мета-тег Title** (назва магазину)
   - **Мета-тег Description** (опис магазину)
   - **Мета-тег Keywords** (ключові слова)

3. Для кожного товару/категорії:
   - **Каталог** → **Товари/Категорії**
   - Вкладка **Дані** → заповніть SEO поля

<script>

  (i[r].q=i[r].q||[]).push(arguments)},i[r].l=1*new Date();a=s.createElement(o),

## Вирішення проблем

### Шаблон не відображається

**Проблема:** Після активації шаблон не застосовується

**Рішення:**
1. Очистіть кеш: **Система** → **Обслуговування** → **Очистити**
2. Перевірте права доступу до папок (755)
3. Перевірте, що всі файли завантажені
4. Очистіть кеш браузера (Ctrl+Shift+Delete)

### CSS стилі не працюють

**Проблема:** Сторінка відображається без стилів

**Рішення:**
1. Перевірте шлях до CSS файлів у `header.tpl`
2. Очистіть кеш системи та браузера
3. Перевірте консоль браузера (F12) на наявність помилок 404

### Зображення не відображаються

**Проблема:** Товари без картинок

**Рішення:**
1. Перевірте права доступу до папки `image/` (755)
2. Перевірте права доступу до `image/cache/` (777)
3. **Система** → **Налаштування** → перевірте шлях до зображень

### Проблеми з адаптивністю

**Проблема:** На мобільних пристроях некоректне відображення

**Рішення:**
1. Перевірте наявність файлу `responsive.css`
2. Перевірте мета-тег viewport у `header.tpl`:
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
3. Очистіть кеш

### Помилки JavaScript

**Проблема:** Не працює кошик або інші функції

**Рішення:**
1. Перевірте підключення jQuery
2. Перевірте консоль браузера (F12)
3. Перевірте файл `common.js`

## Резервне копіювання

Перед будь-якими змінами робіть резервну копію:

1. **Файли:**
   - Завантажте папку `catalog/view/theme/`

2. **База даних:**
   - **Система** → **Обслуговування** → **Резервне копіювання**
   - Оберіть всі таблиці
   - Натисніть **Резервна копія**

## Оновлення шаблону

При виході нової версії:

1. Зробіть резервну копію
2. Завантажте нові файли
3. Збережіть ваші налаштування (кольори, логотип)
4. Очистіть кеш
5. Перевірте сайт
