# TechnoDron - Шаблон для ocStore 2.3.0.2.4

Професійний шаблон для інтернет-магазину систем безпеки та відеоспостереження tehnodron.in.ua

## Опис

Сучасний та адаптивний шаблон для платформи ocStore 2.3.0.2.4, спеціально розроблений для українського інтернет-магазину систем безпеки. Шаблон оптимізований для продажу камер відеоспостереження, відеореєстраторів, охоронних сигналізацій та систем контролю доступу.

## Встановлення

### Крок 1: Завантаження файлів

1. Завантажте папку `catalog` на ваш сервер
2. Розмістіть файли в кореневій директорії ocStore

### Крок 2: Активація шаблону

1. Увійдіть до адмін-панелі ocStore
2. Перейдіть до **Система** → **Налаштування**
3. Виберіть ваш магазин та натисніть **Редагувати**
4. Перейдіть на вкладку **Магазин**
5. У полі **Шаблон** виберіть `tehnodron`
6. Збережіть зміни

### Крок 3: Налаштування мови

1. Перейдіть до **Система** → **Локалізація** → **Мови**
2. Переконайтеся, що українська мова активована
3. За необхідності встановіть українську мову як основну

## Налаштування

### Логотип

1. Підготуйте логотип у форматі PNG (рекомендований розмір: 200x60px)
2. Завантажте через **Система** → **Налаштування** → вкладка **Магазин** → **Логотип**

### Кольорова схема

Основні кольори шаблону можна змінити у файлі `stylesheet.css`:

```css
/* Основний колір - червоний */
#e74c3c

/* Додатковий колір - темно-синій */
#2c3e50

/* Колір для кнопок та акцентів */
#27ae60
```

### Категорії на головній сторінці

Відредагуйте файл `template/common/home.tpl` для додавання ваших категорій товарів.

### Контактна інформація

Оновіть контакти в футері (`template/common/footer.tpl`).
